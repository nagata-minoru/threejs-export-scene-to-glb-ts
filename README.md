# threejs-export-scene-to-glb-ts

## REQUIREMENTS

- [Node.js](https://nodejs.org)

## セットアップ

```shell
npm install
npm run dev          # 開発サーバ(http://localhost:5173)
npm run build        # 本番ビルド(dist/ に出力)
npm run preview      # ビルド結果をローカルで確認
```

## 使用方法

`npm run dev` で起動した開発サーバをブラウザで開く。

## GitHub Pagesで公開

```
npm run deploy
```
